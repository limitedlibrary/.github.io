シミュレーションゲーム

3Dフィールド上でユニット配置を行う戦略シミュレーション試作

スクリーンショット

概要

3Dフィールド上に味方ユニットを配置し、 ステージごとに戦闘準備を行う戦略シミュレーションゲームの試作です。

ユニットの配置範囲、ステージ管理、キャラクター情報の表示、 戦闘開始までの流れを実装しました。

Siv3Dを使った3D表現とUI制作、 Codexを活用した制作フローを試す目的で制作しました。

作品情報

ジャンル：戦略シミュレーション

開発期間：約1か月

制作位置づけ：月刊試作の3作目

使用技術

  • C++
  • Siv3D
  • Visual Studio
  • Codex

制作で学んだこと

  • Codexを使った制作フロー
  • Siv3Dの導入と基本的な使い方
  • Siv3Dによる3D表示
  • 3Dフィールド上でのユニット配置
  • ステージ管理
  • UI表示と操作処理

今後の改善点

  • 3Dモデルの読み込み方法の整理
  • OBJ形式モデルの読み込み
  • 戦闘パートの作り込み
  • ユニットやステージの種類追加

ひとこと

Siv3Dはサンプルやチュートリアルが豊富で、 試作だけで終わらせるよりも、月刊制作とは別枠でじっくり学びたいと感じた作品です。
